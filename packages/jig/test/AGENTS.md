# Jig test suites

## Ownership

- `portable/` owns source checks without native host admission or model
  credentials.
- `linux/` owns Linux platform checks that can run in the ordinary source job.
- `filesystem/` owns descriptor capture on Linux and explicitly qualified native
  Macs.
- `host/` owns native lifecycle and installed public consumer scenarios shared
  by Linux and Mac.
- `linux-host/` owns delegated rootless Linux admission, enforcement and
  recovery.
- `macos/` owns native Mac enforcement and recovery. `macos-23E224/` owns the
  exact Intel preference observer profile.
- `startup/` owns real offline native client startup in the installed
  qualification step.
- `live/` owns separately authorized subscription, API and restoration
  qualifications.
- `experimental/image-preview.test.ts` owns the explicitly opted-in, unqualified
  thread-renderer candidate. It is not part of release qualification.
- `fixtures/` and root `*.fixture.ts` modules own shared construction and
  assertions. They register no tests and acquire no native owners on import.
  Each case owns fresh project capture, admission, Run, durable state and
  cleanup. The private `fixtures/incident-brief/test/` application owns
  separately registered deterministic method cases in the applications profile.

## Execution contracts

Follow the maintainer guide's
[no-mocks rule](../../../.agents/maintainer-guide.md#test-real-boundaries-never-mocks).
Use actual stores, processes and qualified native owners for lifecycle evidence.
Keep remaining migration gaps in `.tmp/`. Never treat replacement behavior as
passing product evidence.

Compare JSON evidence by exact keys, primitive types and values, and array order,
not JavaScript object prototypes. This does not replace authenticity or
object-identity checks for local owners and descriptors.

`scripts/ci/test-suites.json` owns whole-file applicability. The shared suite
inventory refuses unknown or ambiguous files. Select suites before execution.
Selected suites must execute positively with zero skipped or filtered cases.
Missing native flags, exact host prerequisites or live inputs fail the selected
suite. Parameterized cases have explicit unique registration names.

Attach rejection handlers with `Promise.then` before the action that settles them.
Bun's asynchronous expectation matchers can wait synchronously.
Run those matchers only after admission or the required process signal.

Do not add name-pattern partitions or frozen line/name skip exceptions.

Each independent native backend fixture Run plan receives a fresh absolute
deadline for its existing duration when constructed. A plan spread from a
completed Run must not carry that spent deadline into another fresh owner. Never
reset a sealed or active Run deadline.

## HTTP readonly qualification

The packed HTTP composition suite reports plan and apply failures through the
existing session observer. Emit only the fixed scenario, operation and bounded
class/code causes. Observer failures preserve the original operation error.
This diagnostic does not change evaluator limits or prove a host cause.

The packed HTTP Agent coordinator-loss barrier projects existing coordinator
stderr only on failure. Emit closed phase, error-class and code allowlists,
collection status and finite counts, never raw stderr or request contents.
Limit input to 16 KiB, eight records, and eight causes per record.
Projection failures preserve the assertion. Process teardown preserves both errors.
Portable parser cases prove redaction and bounds, not native execution.

The actual contained-effect fixture captures the generated HTTP intent, proves
file-only Mac lowering and unchanged Linux lowering, and retains
failure/cancellation cleanup and diagnostic privacy. Native scope tests require
exact zero-tree root cwd, refuse near-matching and unrelated-tree alternatives,
and prove denied writes/private-control reads through the real launcher. Held
HTTP lifecycle cases first bind the exact fresh Run/effect allocation and sealed
owner. They then prove its Mac storage is absent. They retain
cancellation/coordinator-loss fencing and final owner cleanup. The offline
localhost TLS case uses the qualified real Node HTTPS peer to count actual TCP
connections independently of Bun server shims.

It uses fresh private readiness and bounded subprocess closure inside the
existing case budget. It still requires name resolution, a positive connection
count, ordinary client certificate refusal and zero HTTP requests. Peer
handshake events cannot establish client trust. It does not establish successful
public HTTPS. Run the whole HTTP lifecycle and packed HTTP Agent composition
suites on Linux and both qualified Macs before release acceptance.

## Verification

Preserve every existing test body, case input, timeout and cleanup assertion
when moving a suite. Retain before/after migration evidence, then run complete
source checks and native regression on the matching profile. CI must reconcile
every planned file exactly once against successful reports. Platform-specific
omissions are applicability decisions, never a passing qualification. Timing
weights only place work. They cannot change inventory or evidence.
