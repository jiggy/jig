# Disposable API ledger

| Probe surface | Need | Pressure exposed | Disposition |
|---|---|---|---|
| `flows: discover("./flows")` | Admit ordinary package membership once. | Two self-contained exact Runs should become usable without authored Binding files. | Existing discovery plus narrow derived defaults. |
| `bindings: ["./bindings/dispatcher.ts"]` | Admit one intentional customization. | An open child-selection policy must be visible and reviewable. | Existing exact source form. |
| `allRuns()` | Map one `flow/call` slot to every other normalized Run in the candidate generation. | Open selection needs an exact finite snapshot, not implicit catalogue access. | Candidate helper under test; non-generic and legal only for a `flow/call` Binding slot. |
| `run.flows.call(...)` | Perform the selected child operation. | The executable names only its local slot; Jig owns resolution. | Shared candidate `@flowmd/sdk` projection. |
| Derived `echo-upper` and `echo-reverse` Bindings | Exercise defaults across Bun and Python. | Native dependencies do not themselves require tailored Bindings. | Same ordinary normalized Binding branch, with diagnostic origin only. |

## Deliberately absent

There is no Semantic Choice Binding, Agent, Service, Hook, attachment, setting,
grant object, ambient authority, automatic apply, per-call catalogue scan, or
runner-specific graph API. Two surviving candidates are therefore
deterministically ambiguous in this probe.

The exact Package/1 digests in `expected/normalized-plan.json` are fixture
facts. This probe does not invent the still-release-gated canonical
`jig.lock`/Binding-revision hash format.
