# Disposable API ledger

| Probe surface | Need | Existing concept | Pressure exposed | Disposition |
|---|---|---|---|---|
| `flows: discover("./flows")` | Admit ordinary package membership once. | Project source discovery. | An eligible member can propose one default use without another source file. | Existing syntax; corrected normalization. |
| Derived `greet` Binding | Execute one genuinely zero-configuration Run. | Immutable Binding identity and admission. | Binding files are customization, not mandatory boilerplate. | New narrow normalization rule. |
| `jig run greet` | Start through the existing root path. | `startRun(bindingId, input, submissionId)`. | No target union or raw package execution is needed. | Existing semantics. |
| `serveRun(...)` | Project Run/1 through a real future SDK surface. | FLOW Run/1 SDK. | `@flowmd/sdk` is an ordinary declared native dependency, not Adapter injection. | Preferred future package/API spelling. |
| Empty settings/slots/attachments | Prove a true default rather than hidden configuration. | Schema absence and portable sandbox baseline. | Jig inserts no schema defaults and selects no capability provider. | Required for derivation. |

## Deliberately absent

There is no `bindings/`, `hooks/`, Service, Agent, semantic choice, capability
slot, attachment, settings schema, grant object, instruction fallback,
final-Run raw network, environment interpolation, or implicit auto-apply.
