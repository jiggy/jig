# Expected defaults-only lifecycle

1. Discovery captures `flows/greet` as inert package source.
2. Normalization proves the directory and `FLOW.md.name` both equal `greet`,
   the package is exact-code Run-capable, `{}` is legal settings, and no
   attachment, capability, Service, or instruction choice exists.
3. Jig proposes one ordinary normalized Binding with origin
   `derived-default`. The plan shows its baseline authority; nothing runs.
4. Aggregate apply admits the exact package, Binding revision, lock result,
   Adapter recipe, Sandbox plan, and generation.
5. `jig run greet` enters the existing idempotent root admission path. It never
   addresses raw source.
6. Jig validates input, prepares and launches through the pinned Adapter and
   Backend, sends `flow/run`, validates the complete result, and commits it.
7. Revocation, cancellation, uncertainty, and inspection behave exactly as for
   an explicitly declared Binding.
