# Disposable API ledger

The probe uses hypothetical syntax to expose design pressure. It does not win
against the specifications and must not freeze an API accidentally.

| Probe surface | User need | Current specification concept | Assumption or open question | Disposition |
|---|---|---|---|---|
| `defineJig({...})` | Return one project desired-state definition. | [`jig.ts` convention](../../docs/spec/project-policy.md#1-default-project-convention) | Function name and complete type are unimplemented. | Candidate root constructor. |
| `discover("./flows")`, `discover("./bindings")`, `discover("./hooks")` | Opt into shallow conventional roots once without leaking internal source kinds. | [Project sources](../../docs/spec/project-policy.md#1-default-project-convention) | The containing field supplies the kind; v1 rejects globs and recursion. | Candidate spelling; stable deterministic semantics. |
| `semanticChoice: "semantic-choice"` | Pin one project-wide optional ambiguity ranker Binding. | [Semantic Choice §6](../../docs/spec/agents-and-semantic-choice.md#6-two-intentional-routing-sites) | It never replaces deterministic resolution or configures local Routers. | Candidate direct reference; wrapper removed. |
| `bind({...})` | Declare one inert configured use. | [Closed Binding union](../../docs/spec/project-policy.md#2-one-closed-binding-union) | Stub accepts only fields exercised here. | Candidate. |
| `hostCapability(provider, { export })` | Select one installed trusted export without installing it. | [Host-capability branch](../../docs/spec/project-policy.md#2-one-closed-binding-union) | Provider names are illustrative; real registrations must pin exact contracts and schemas. | Stable semantics; candidate spelling. |
| `bindingRef(name)` | Resolve one local dependency to an admitted exact revision. | [Binding dependencies](../../docs/spec/project-policy.md#3-declaration-files) | It must not import a live object or act as an Agent profile. | Stable semantics; candidate spelling. |
| `root(path)` | Map a declared logical attachment to a project root. | [Security and attachments](../../docs/design-review/60-reviewed-architecture.md#11-security-and-trust) | Mapping does not choose or weaken the host Backend. | Stable concept; candidate spelling. |
| Journal Binding `grants.eventTypes` | Attenuate one producer to a finite Event namespace. | [Journal authority](../../docs/spec/journal-and-hooks.md#2-authority-idempotency-and-atomicity) | Trusted Journal registration owns the exact authority schema; this is an illustrative registration-defined grant, not a universal `eventTypes` field. | **Provider-defined API, not a Jig generic.** |
| Agent Binding `grants.tools` | Bound writer and repair Agents to the registration-declared mediated file and command tools needed by their work. | [Agent authority](../../docs/spec/agents-and-semantic-choice.md#3-workspace-and-authority) | The illustrative names require one real provider registration schema and exact authority receipt; they are not portable raw-process grants. | **Provider-defined API, not a Jig generic.** |
| `hook({...})` | Declare exact Event source/type to exact Run Binding. | [Hooks](../../docs/spec/journal-and-hooks.md#3-hooks) | Exact closed declaration is specified; runtime callback APIs are intentionally absent. | Stable behavior. |
| `candidates([Binding IDs])` | Freeze an approved allowlist for one `flow/call` slot without pretending to discover source or choose immediately. | [Binding references](../../docs/spec/project-policy.md#3-declaration-files) | V1 defers bulk materialization. Zero and ambiguity have fixed terminal semantics; no per-slot ranker or rewritten intent exists. | Candidate spelling; distinct from project `discover()`. |
| Package `instruction.agent` | Pin the conductor Agent for an instruction-only Flow. | [Package Binding instruction rules](../../docs/spec/project-policy.md#2-one-closed-binding-union) | Stub uses `bindingRef`; normalized form must pin a projection-capable host Agent contract/export/runtime revision. Service-backed Agents remain ordinary-call providers only when no Flow-local skill projection is needed. | Stable semantics; spelling candidate. |
| `Node`, `Flow`, `Agent`, `Router`, `Parallel`, `Outcome` | Review inheritance-oriented Spindle ergonomics with one explicit fork/join. | [Spindle boundary](../../docs/design-review/60-reviewed-architecture.md#144-spindle) | Exact constructors and graph compilation remain unimplemented. `Outcome` alone terminates and propagates; omitted output means `{}`, while an unconnected ordinary leaf is an error. | Disposable syntax around stable minimal state and termination rules. |
| Immutable `{ root, state }` and Node-returned next state | Carry child results and deliberate history without a mutable bag, filesystem smuggling, or Jig mapper DSL. | [Spindle dataflow](../../docs/design-review/60-reviewed-architecture.md#144-spindle) | The probe initializes `{ event }`, then ordinary Node code adds reference/Agent/vote results. | Stable semantic rule; API spelling remains exploratory. |
| `Router.to(id, Node, description)` | Describe actual finite graph edges to Semantic Choice. | [Runner-local Router](../../docs/spec/agents-and-semantic-choice.md#runner-local-router) | IDs are local and opaque; Nodes include nested Flows, and there are no route arguments or dynamic graph mutations. | Stable semantics; candidate syntax. |
| Workflow-specific classes extending `Agent` | Call an exact Agent effect while ordinary code explicitly shapes the next immutable state. | [Agent Run and authority](../../docs/spec/agents-and-semantic-choice.md#1-three-non-substitutable-agent-contracts) | Spindle derives stable operation IDs from node visit plus local key. Workspace/effect authority comes from the exact Agent Binding; the caller receives no matching direct view. | Preferred minimal inheritance direction; exact API open. |
| `context.flows.call(localOperation, {...})` | Cross the component boundary through generic `flow/call` and retain the result explicitly. | [Resolver lifecycle](../../docs/spec/agents-and-semantic-choice.md#jig-open-ended-resolver) | Contract-free calls return JSON/1, not a trusted generic. `Research` validates the `Reference` shape in ordinary code; `FlowCall` sugar was removed because it did not solve either state flow or compatibility. | Primitive semantics stable; exact SDK spelling exploratory. |
| `serve(async run => result)`, attachment `resolve()`, and `run.effects.call(...)` | Make the exact producer and small portable Flows complete enough to trace. | [FLOW Run/1](../../docs/design-review/60-reviewed-architecture.md#5-flow-run1) | `@flow/run` is a hypothetical ordinary native dependency; attachment helpers grant no authority and SDK/lock distribution remains unimplemented. The SDK validates and unwraps contract `{value}` successes, exposes declared `{error}` as catchable capability errors, and rejects host/protocol failures. | Smallest language projection under test, not another protocol. |
| Package-local contract descriptor paths | Keep strict public capability compatibility without handwritten hashes in `FLOW.md`. | [Capability loading](../../docs/spec/capability-contracts.md#4-package-declarations-and-loading) | Exact descriptors are duplicated deliberately in rare consumers; Jig derives and locks the triple. | Stable progressive contract rule. |
| Instructions which name `focused-validation` | Make intended Skill use visible. | [Flow-local Skills](../../docs/spec/agents-and-semantic-choice.md#31-flow-local-skills) | Projection proves availability only; Agent use/compliance cannot be guaranteed. | Corrected probe claim; no Agent `skills` argument. |
| `#!/usr/bin/env spindle` | Narrow Adapter selection for the exact graph package. | [Runtime Adapter selector](../../docs/spec/runtime-adapters.md#optional-selector-line) | Token mapping is host-local; it is never an OS command. | Stable file convention. |
| Omitted `jig.lock` | Let a fresh project expose bootstrap ergonomics without inventing serialization. | [Consent and lock](../../docs/spec/project-policy.md#7-consent-and-the-lock) | First unlocked plan proposes it; locked mode rejects. | Stable bootstrap, byte format open. |
| Operator-started `create-missing-flow` | Repair missing structure without mutating a terminal failed operation. | [Missing repair](../../docs/spec/agents-and-semantic-choice.md#jig-open-ended-resolver) | Importing staged proposal files has no special host API here; normal project editing and plan/apply own it. | Stable separation; no automatic resume. |
| `expected/*` | Table-top normalized state and failures before code exists. | Future inspection and conformance outputs. | Shapes are probe-local and intentionally not a trace protocol. | Replace, never preserve. |

## Surfaces deliberately not invented

There is no API here for an inbox watcher, Service mount, Task, Kanban, Git,
worktree allocation, Agent sessions, skill selection, route arguments,
per-Run settings, automatic repair, `WAITING_BINDING`, Hook callbacks,
telemetry, Runtime Adapter preference, Sandbox Backend selection, raw commands,
or host permission flags.
