Direct-run alpha

Run exact workflows. Keep authority explicit.

FLOW packages are ordinary editable files. Jig captures their exact meaning, asks you to approve changes, and runs only admitted bytes in a rootless Linux boundary.

Quickstart Read the specifications

Three commands

jig init --bare my-project
jig check
jig run flow:flows/hello

One review boundary

Source proposes. An explicit review admits one immutable project generation. Live files never silently become execution authority.

One secure host

The first alpha supports one fail-closed Linux, cgroup-v2, systemd, and Bubblewrap path. There is no privileged or weaker fallback.

FLOW is openly implementable and founder-stewarded. Jig is prerelease software.
