# Show what developers can build

Promotional materials translate the [audience strategy](../audience.md) and
[communication guide](../communication.md) into concrete demonstrations. They
remain subordinate to product doctrine and the actual public interfaces.

| Material | What it demonstrates |
| --- | --- |
| [First video: a CSV importer](video-01-contact-import.md) | One product feature calls a mapping method implemented with code, an Agent, or both within the current root-to-leaf execution profile. |

Keep source applications in `examples/`, public usage instructions alongside
them or in `docs/`, and recording/rehearsal artifacts in `.tmp/`.
