# Contact import

## Purpose

Show a product feature composing the same mapping contract with code, an Agent,
or both, then using ordinary code to produce a contact preview.

## Ownership

- `flows/import` owns the short coordinator and one typed Contact preview page.
- `flows/read-contacts` owns bounded CSV capture and parsing with read-only source.
- `flows/export-preview` writes supplied preview JSON into its own output
  attachment. The coordinator checks metadata before exposing
  `contacts/preview.json`.
- `flows/map-code`, `map-agent`, and `map-mixed` implement the mapping contract.
- `flows/convert` owns mapping validity and row acceptance rules.
- `bindings` selects methods. `fixtures` and `test` own synthetic
  demonstrations.

- `bindings/model.ts` owns the inline ACP client/model/turn/session policy.
  The default `jig.ts` selects only code-path packages and the code Binding.
  The README shows ordinary discovery and contract-keyed Agent selection for
  enabling intelligent alternatives. New selected Agent policy needs review.
  Each mapper keeps its small private response schema beside the Agent call.
  Conversion retains the independent index and row checks.

## Local Contracts

- `jig.ts` owns the complete default invocation:
  `binding:code --input '{}' --attach source=fixtures/known --timeout 1m`.
  Ordinary `jig run` uses reviewed defaults and receives a fresh temporary
  packet for its writable preview. The README explains temporary cleanup and
  optional retained `--out` destinations without overwrite behavior. Explicit
  targets bypass defaults. Display choices remain operator options.

- Complexity cap: one CSV, one contact schema, column selection only, final preview.
  No database writes, transformations generated by models, OCR, Excel, interactive editing,
  queues, or interactive streaming. Mapping substitution is the single lesson.
- The Agent receives headings only. Rows remain with code. Headings may
  themselves contain sensitive data. Provider selection belongs to the
  operator.
- Mapping uses three distinct existing column indices. Null means clarification
  is needed. Both intelligent mappers require exactly the three own field keys.
  Every proposed value must be null or a safe integer. Check these requirements
  before collapsing an abstention to a null mapping. The converter independently
  checks distinct indices and actual column bounds.

  Structural validity never proves semantic correspondence.
- Input is `source/contacts.csv`: UTF-8, 64 KiB, 1–100 data records, 1–16
  columns.
- `preview.json` is a proposal for review, not an import receipt. `ready`
  describes a completed preview, even when some or all rows are rejected.
- Keep each Flow self-contained. The mixed mapper uses code and an ordinary
  Agent Flow through its declared slot. `bindings/model.ts` selects the
  operator's Agent and grants. Contract-keyed defaults supply it to both
  intelligent mappers. Keep its small known-format rule aligned through shared
  test cases, not imports of a sibling Flow implementation.
- Uncertain execution, failure, and cancellation propagate without retries.

- The coordinator’s `dashboard.ts` projects a small typed state into one
  Contact preview page with mapping, accepted records, correction reasons and
  export access. All child Flows have independent optional domain views
  through `progress`. FLOW entrypoints own scoped publishers, activity and
  failure notices. Pure methods retain their exact results and policy. The
  existing reporting profile serves terminal and web without display code.
  Tests validate complete escaped items, provisional meanings and evidence
  links.

## Work Guidance

- Reader and exporter are composed through declared attachment maps. The root
  writes no files. Exported data is a preview, never an import receipt.
- Retain recognizable malformed, unknown, ambiguous, and row-rejection cases.
- Fault injection must be identified as a deterministic test, never live model
  evidence.

## Verification

  reports.
- `scripts/test-release.sh` repeats these tests with the packed SDK.
- Use an admitted installed run separately before claiming host or live Agent
