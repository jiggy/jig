# Project Evaluation contract

`https://jig.md/contracts/project-evaluation` identifies Jig's controlled
Bun/TypeScript candidate evaluator. It is an offline invocation identity, not an
HTTP execution service or a permission by itself.

Read the [specification](../spec/project-evaluation.md) for the authority,
process evidence, limits and qualification boundary. The exact downloadable
[descriptor](https://jig.md/contracts/project-evaluation/contract.json) is matched by
identity, version and digest; copying it never grants execution authority.
