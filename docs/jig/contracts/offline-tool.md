# Offline Tool contract

`https://jig.md/contracts/offline-tool` identifies a Jig invocation for
passing held files to a reviewed, offline executable and collecting its files.
An operator grants this authority in a Binding.

See the [Offline Tool specification](../spec/offline-tool.md) for installation,
review, file custody and lifecycle. Download the exact
[descriptor](https://jig.md/contracts/offline-tool/contract.json) or import it
with `jig import-contract jig:offline-tool`.
