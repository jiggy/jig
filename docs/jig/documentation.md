# Build with code and Agents

Jig lets your application call reusable methods that use code, Agent judgment, or both.
You choose their powers, review the source, and handle their results.

Start with one method called a **Flow**.
Run it locally, call it from an application, then add the Agent work your task needs.

## Start with a working result

| Your starting point | Follow this path | You will have |
| --- | --- | --- |
| New to Jig | [Run your first Flow](./start/index.md) | A greeting method you can review, run, and change. |
| Ready to use a method in software | [Call from your application](./start/application.md) | A program that invokes the same method and checks its result. |
| Ready to add intelligence | [Add an Agent](./build/agents.md) | An Agent method using your chosen API or native client. |
| Already have several methods | [Compose methods](./build/compose.md) | A caller that invokes children through reviewed dependencies. |

The first two tutorials use the same project and need no Agent credentials.
Check the [supported host requirements](./start/index.md#supported-host) before installing.
