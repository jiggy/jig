01 · Run your first Flow Developer alpha · Check Linux & Mac requirements ↗
# Install Jig, then make a small project
$ npm install --global @jigging/jig@alpha
$ jig init hello-jig
$ cd hello-jig

# Review the source, then approve it
$ jig review --allow-resolution-network

# Run the approved method
$ jig run flow:flows/hello --input '"Ada"'
Hello, Ada!Your first result.

Review may access the network to resolve dependencies. Inspect the source and policy before approving.
