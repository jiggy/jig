# Acknowledgements

## Establishing the Jiggy home

Thank you to the people whose work helped establish the project family's home:

- [@jiggyzzzz](https://github.com/jiggyzzzz), the former owner of GitHub's
  `jiggy` personal account, [made `jiggy` an organization and invited
  @zvictor as an owner](https://github.com/jiggy/sley/issues/2#issuecomment-5548866452).
  This enabled the [confirmed move of the project repositories into Jiggy](https://github.com/jiggy/sley/issues/2#issuecomment-5550855870).
- [@breautek](https://github.com/breautek), an original maintainer of the earlier
  Jiggy 2D engine, [coordinated consent with the other maintainer](https://github.com/jiggy/sley/issues/2#issuecomment-5453339799)
  and [investigated recovery of the account controlling npm's `@jiggy` organization](https://github.com/jiggy/sley/issues/2#issuecomment-5510581148).
  That recovery [was denied](https://github.com/jiggy/sley/issues/2#issuecomment-5745956171),
  so the npm `@jiggy` organization was not transferred. We appreciate the
  work even though it could not complete the npm handover.

These acknowledgements recognize actual contributions recorded in
[Sley issue #2](https://github.com/jiggy/sley/issues/2). The earlier Jiggy
2D engine's authorship and history remain distinct.
