# FLOW working-group scope

The FLOW working group develops portable contracts for:

- bounded JSON values and schemas;
- FLOW packages, invocation contracts and channel contracts;
- the Run protocol; and
- the observable behavior of portable FLOW SDKs.

The normative files covered by this scope are the FLOW specifications under
`docs/flow/spec/`, as identified in [`LICENSES.md`](LICENSES.md), including
revisions proposed for a future FLOW version.

Jig project policy, admission, containment, durability, administration, and
user-interface behavior are outside this scope. So are the internal semantics
of Sley or any other component runtime and the implementation details of an
SDK, host, agent provider, sandbox, package manager, or catalogue.
